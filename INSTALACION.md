# Cómo instalar este README

1. Copiá `README.md` a la raíz del repositorio.
2. Copiá la carpeta `assets/` junto al README.
3. Hacé commit de ambos.
4. Los SVG se referencian con rutas relativas (`./assets/...`), por lo que funcionarán directamente dentro del repositorio.

La tipografía Caveat/Lora se declara dentro de los SVG y usa Georgia/cursiva como fallback. El contenido Markdown no puede heredar el CSS de tu portfolio directamente desde GitHub.
